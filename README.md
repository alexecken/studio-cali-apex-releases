# Studio Cali Apex — versions publiées

Installateur Windows et mises à jour du studio de montage Cali Apex.

**Installer :** télécharger `StudioCaliApex-Setup-x.y.z.exe` dans la dernière release (Releases → Latest), double-cliquer, puis « Informations complémentaires → Exécuter quand même » si Windows le demande.

Les mises à jour suivantes s'installent depuis le studio (bouton « Mettre à jour »). Le code source est dans un dépôt privé.
